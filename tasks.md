# ATL (Agentic Task List)

This file tracks tasks for multi-agent orchestration. Each worktree section represents an isolated workspace.

## Task Status Legend
- `[]` - Not started (ready for pickup)
- `[⏰]` - Blocked (waiting on prior tasks)
- `[🟡, <adw_id>]` - In progress
- `[✅ <commit>, <adw_id>]` - Completed successfully
- `[❌, <adw_id>]` - Failed

## Git Worktree main
Tasks that run directly on the main branch (no isolation needed).
