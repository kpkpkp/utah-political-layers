**File:** `utah-political-layers-standalone.html` (15 MB)

### Features:
- ✅ **Works offline** - no internet needed
- ✅ **Single file** - email, Dropbox, USB drive
- ✅ **Self-contained** - all data embedded
- ✅ **Zero dependencies** (except CDN for Leaflet)

### How to Share:
1. **Email:** Attach the file (may need to compress to ZIP)
2. **Cloud:** Upload to Google Drive, Dropbox, OneDrive
3. **USB:** Copy to flash drive for offline presentations
4. **WeTransfer:** For large file transfers

### How to Use:
- Recipients just double-click to open in their browser
- Works on Windows, Mac, Linux
- No installation or setup required

### Rebuild After Changes:
```bash
node build-standalone.js
# Creates updated utah-political-layers-standalone.html
```
